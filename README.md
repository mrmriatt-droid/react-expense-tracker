# Expense Tracker 💰

An expense tracking app built with React and Vite.

## Features

- Add new expenses
- Edit and delete expenses
- Search for expenses
- Filter expenses by category
- Sort expenses by amount and date
- Track monthly expenses
- Set a monthly budget
- View remaining budget and spending progress
- Save expenses and budget using localStorage

## Technologies

- React
- JavaScript
- CSS
- Vite

## Run Locally

1. Clone the repository
2. Run `npm install`
3. Run `npm run dev`
